Help Desk – Ticket Yönetim Sistemi

ASP.NET Core Web API ve Angular kullanılarak geliştirilen bir Help Desk (Destek Talep Yönetimi) uygulamasıdır.

Projenin amacı, kullanıcıların teknik destek talepleri oluşturabilmesini ve IT personelinin bu talepleri yönetebilmesini sağlamaktır.

Kullanılan Teknolojiler

* ASP.NET Core Web API (.NET 10)
* Microsoft SQL Server
* Angular
* Swagger / OpenAPI
* Git & GitHub
