Help Desk – Ticket Yönetim Sistemi

ASP.NET Core Web API ve Entity Framework Core kullanılarak geliştirilen bir Help Desk (Destek Talep Yönetimi) uygulamasıdır.

Projenin amacı, kullanıcıların teknik destek talepleri oluşturabilmesini ve IT personelinin bu talepleri yönetebilmesini sağlamaktır.

🚀 Kullanılan Teknolojiler

* C#
* ASP.NET Core Web API (.NET 10)
* Entity Framework Core
* Microsoft SQL Server
* Swagger / OpenAPI
* Git & GitHub
